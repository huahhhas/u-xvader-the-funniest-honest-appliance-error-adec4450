# The Funniest Honest Appliance Error

One line: the funniest honest error message an appliance could show.

## Entry

> ERROR 04: Drum will not spin. Your duvet has formed a union and refuses to be wrung out. Please redistribute the load and my dignity.

A washing machine, deadpan, telling the truth about an unbalanced load.

## Run

```sh
python3 main.py
```

Prints the entry line to stdout and writes it to `/output/entry.txt`.
